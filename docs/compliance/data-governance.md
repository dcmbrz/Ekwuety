# Compliance and Data Governance

## Data Sources

All knowledge pack sources must meet:
- License compatibility (MIT, Apache, Creative Commons)
- Data quality verification
- African content authenticity verification

## Privacy

- No personal data collection in search queries
- Local processing on edge devices
- Encrypted sync for knowledge packs

## Regional Compliance

- GDPR compliance for EU users
- POPIA compliance (South Africa)
- NDPR compliance (Nigeria)
- LGPD compliance (Brazil)

## Content Guidelines

- Verified sources only
- No copyrighted content without license
- Cultural sensitivity review for all content
